- Data schema and privacy architecture

## Versioning Approach

This project follows semantic versioning for documentation releases:

- **Major (1.0.0):** Fundamental restructuring or breaking changes to protocol
- **Minor (0.X.0):** New documentation sections or significant feature additions
- **Patch (0.0.X):** Corrections, clarifications, small improvements

Documentation versions are independent of Field Journal software versions.
